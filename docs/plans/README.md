# Implementation plans

Plans are implementation specifications produced after architect review of a substantial gameplay change.

## Naming

Use the filename pattern `YYYY-MM-DD-<slug>.md` (for example, `2026-11-06-shared-activation-targeting.md`).

## Usage

The engineering workflow rule references these documents. The **implementer** and **tester** subagents should read the approved plan path when implementing or verifying work.
