# Status Effects

### Status effects

| Status | Effect |
| --- | --- |
| Silence | Blocks active abilities (items still work) |
| Mute | Blocks active items (abilities still work) |
| Sleep | Blocks abilities, movement and attacks until damaged or expired (an item channel is not interrupted) |
| Stun | Blocks move, attack, and abilities |
| Root | Blocks movement |
| Disarm | Blocks attacking |
| Debuff immunity | Blocks new debuffs (Barrier) |
| Shield | Absorbs damage before HP (`ShieldPool`; Barrier also grants bonus armor) |
| Burn | DoT via `damage_per_sec` → `DamageEvent` each frame |
| Phased / Forceful | Collision ignore / stronger soft-separation |
| Flying | Walks over trees and other props (towers and ancients still block); forced movement ignores terrain; sets the unit down on walkable ground when it ends |
| Leash / Tether | Clamps the unit inside a circle around a fixed point (Leash) or around the caster (Tether); basic-dispellable debuffs that never break; a teleport outside the circle is rejected |
| Cyclone | Lifts and holds the unit: stun + invulnerable + **untargetable**, undispellable, immune to other displacement and teleports |
| Untargetable | `apply_status,untargetable`: **targeting only.** Attacks and hostile unit-target spells cannot pick the holder (`TargetIntent::Attack` / `HostileSpell` reject it), so attackers drop it and enemies cannot start a cast on it. Area effects (enemy and ally), dash contact and projectiles already in flight still reach it, and its own caster-targeted effects and friendly spells keep working. Cyclone and banish are a different, **full** `untargetable` (areas, contact and homing projectiles skip the unit too) |
| Move speed bonus | `apply_status,move_speed_bonus`: `percent` of the holder's base move speed (0..400, measured without status deltas, the mirror of slow). The id is `<owner>_move_speed_bonus`; a refresh never compounds and bonuses add to slows |
| Turn rate bonus / slow | `base × (1 + Σ bonus %) × (1 − strongest slow %)` |
| Heal over time | `StatusSpec::HealOverTime` (`heal_per_sec`, ticks through `vitals::apply_heal`); the caster's heal amp is folded in once when applied; heals nothing on a dead unit |
| Heal reduction | Debuff: `heal_reduction` fraction of healing received is negated; the strongest one applies, they do not stack |
| Heal block | Debuff: prevents all healing (direct, over time, leech, regen, conversion) |
| Mana shield | Buff: diverts `absorb` of post-mitigation damage to mana at `damage_per_mana`; the `ShieldPool` absorbs first; works with `while_toggled`; absorbs nothing at 0 mana |
| Blind | Debuff on the **attacker**: `blind_miss_chance` is rolled on the shared `CombatRng` in the attack-hit stage (blinding a unit makes *its* attacks miss; it does not protect it) |
| Evasion | Buff: `StatusSpec::Evasion` / `CombatStats::evasion`; chance that attacks against the holder miss. Sources stack as `1 - prod(1 - e)`; basic-dispellable |
| Accuracy / True strike | Buff: `StatusSpec::Accuracy` / `TrueStrike` / `CombatStats::accuracy`; chance that the holder's attacks land despite blind or evasion. True strike is accuracy 1.0 and ignores both |
| Attack projectile speed | Timed `stat_modifier,attack_projectile_speed` (`Modifier.attack_projectile_speed`): flat change added to `attack_projectile_speed_bonus` (ranged attackers), reverted exactly; negative is a debuff |
| Attack point override | `StatusSpec::AttackPoint` (`apply_status,attack_point`, `value` = seconds 0..1.0, id `<owner>_attack_point`, basic-dispellable buff): `StatusEffect::attack_point_override`, lowest live value wins, read only by `CombatStats::effective_attack_point`, which scales it by attack speed like the base attack point (backswing unchanged); not a stat delta, so nothing to revert |
| Frozen | Buff: `StatusSpec::Frozen` (`apply_status,frozen`): stunned (move / attack / cast / items blocked, channels interrupted) and immune to physical damage. A Buff, so the holder's `dispel,debuff` and debuff immunity leave it alone; an enemy basic `dispel,buff` removes it |
| Taunt onto the cast target | `StatusSpec::TauntCastTarget` (`apply_status,taunt_target`, optional `value` = attack speed bonus while taunted; runtime id `taunt`): the holder is forced to attack the cast's unit target instead of the caster, even its own ally (`basic_attack::attack_allowed`; no cleave / splash, extra attacks stay enemy-only). Only on a `target_type=unit` source and `on_cast` / `on_projectile_hit`; the cast target itself is skipped. Ends with the taunt (dispel, expiry, target death) |
| Attack range | `Modifier.attack_range` / `PassiveStat::AttackRange`: flat bonus to `attack_range`, also tracked in `attack_range_bonus`, so melee units stay melee (`CombatStats::is_melee`) |
| Damage reduction | Buff: `StatusSpec::DamageReduction` / `StatusEffects::damage_taken_factor()` = product of `(1 - r)`; applied to damage taken after armor / resist and `incoming_damage_amp`, for every damage type (pure, DoT ticks, reflection included). Shields still soak the pre-armor amount first |
| Magic resistance (percent) | Buff: `StatusSpec::MagicResistance` / `StatusEffects::magic_damage_factor()` = product of `(1 - f)`; a read-time factor like damage reduction, applied only to magical damage in `apply_damage_events` after the magic-resist rating, so it multiplies with the rating (27.5% hero + 20% takes 100 x 0.725 x 0.8 = 58) and with other percent sources. Nothing is reverted when it ends. The HUD MR stat still shows the rating only |
| Damage share (bond) | Buff: `StatusSpec::DamageShare` (id `damage_share`, `amount` = percent) bonds the holder to the unit that applied it. Every non-reactive hit the holder takes (alive, not invulnerable) is applied in full, and `apply_damage_events` also emits a `reactive` copy of the same pre-mitigation damage, same damage type, to the partner, one frame later (like reflect). The partner applies its own armor / magic resistance, shields, damage reduction and invulnerability; the copy is never re-shared, fires no damage triggers and grants no lifesteal. A later bond replaces an earlier one; a self-sourced bond does nothing; the copy can kill the partner |
| Convert on death | Buff: `StatusSpec::ConvertOnDeath` (id `convert_on_death`, `value` = radius, Basic dispel). `combat::despawn_dead` pays the bounty as usual, then, for a `Creep` that died within the radius (holder centre to victim edge) of the nearest living enemy holder, writes `CreepConvertedEvent`; `units::spawn_converted_creeps` spawns a fresh creep of the holder's team there (same lane and melee / ranged type, full health, normal bounties, creep AI, lane resumed forward via `LaneFollower::resume_from`) with a `Lifetime` of `CONVERTED_CREEP_LIFETIME_SECS` (30 s; an expiry pays no bounty). Heroes, towers and the training dummy never convert; a converted creep that dies near an enemy holder can be converted back |
| Attack charges | Buff: `StatusSpec::AttackCharges` (id `<owner>_attack_charges`, `amount` = attacks, `duration` required): a status that only counts basic attacks and modifies no stat. `status::consume_attack_charges` spends one per released non-extra attack and the status ends at 0 or on its duration, the same path timed `stat_modifier` charges use; gate on it with `require_status`. Flak Cannon uses it |
| Status resistance | Buff: `StatusSpec::StatusResistance` / `StatusEffects::status_resistance_factor()` = product of `(1 - r)`; shortens the duration of finite hostile debuffs (applied by another unit, not held / reactive) as they land, including undispellable ones such as stuns and cyclones; ticking burns keep only the ticks that still fit. Slow amounts, buffs and self-applied debuffs are untouched |
| Stacks | Per-target stacking debuff: `StatusSpec::Stacks` (`<owner>_stacks`, undispellable). Applying it again adds a stack and refreshes the duration; the stacks are lost when it expires. `scaling_type=target_stacks` reads the count |
| Attack charges | `StatusEffect.attack_charges` on a timed `stat_modifier`: each released non-extra basic attack (hit or miss) spends one (`status::consume_attack_charges` writes `StatusChange::ConsumeAttackCharge`); the status ends (`Expired`) at zero or on its duration, whichever comes first. A refresh resets the charges |
| Resource modifier | Timed regen / max / lifesteal / heal amp / cost modifier (`StatusSpec::ResourceModifier`); summed when read, never stored into stats (timed max health / mana is reconciled by `vitals::sync_status_resource_caps`). Timed `strength` / `agility` / `intelligence` are reconciled the same way into `HeroAttributes` by `vitals::sync_status_attributes` (health, mana, armor, attack speed and, for the primary attribute, attack damage follow; attributes never change magic resist; a negative value is a debuff) |
| Independent instances | `StatusEffect.independent` (the `:independent` suffix on a timed `stat_modifier` effect id): each application is its own instance with its own timer instead of refreshing the same-id status. Remove-by-id, dispel and debuff-immunity purge remove every instance; each reports its own lifecycle event |

**Lifecycle events:** every change to a unit's statuses is reported once as a `StatusLifecycleEvent { target, source, id, kind, change }` (`Applied` includes a refresh; `Expired`, `Dispelled` and `Removed` cover expiry, dispel / immunity purge, remove-by-id and the sleep break). The only writers are `apply_status_effect_events`, `tick_status_effects` and the sleep break (`status::wake_from_sleep`, reported by `apply_damage_events`), so nothing can change a status unseen. `OnStatusApplied` / `OnStatusRemoved` read them on the holder. A status that is `reactive` (applied by a reaction, or **held** by a toggle or a `while` row) and every change made by a reactive event is silent: no lifecycle event, so held statuses and reactions never fire status triggers. Held statuses are permanent and undispellable, and are removed exactly when the condition ends, the owner dies or the source is lost.

Walking speed never drops below `scale::MIN_MOVE_SPEED` (100) however many slows stack; there is no upper cap, and units with a base speed of zero stay stationary.
